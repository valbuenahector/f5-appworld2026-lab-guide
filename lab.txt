Summary
Lab Overview:
This two-hour, hands-on lab introduces participants to a modern AI-assisted DevSecOps workflow built around the principle “Code. Secure. Repeat.” Attendees will experience how vibe coding accelerates application development, how CI/CD pipelines enforce security controls, and how F5 Distributed Cloud (F5XC) provides runtime protection and continuous security validation through WAAP and Web App Scanning (WAS).
Lab Objectives:
1.	Introduce Vibe Coding – benefits, flaws, and DevOps acceleration (Module 1).
2.	Demonstrate CI/CD-driven security controls using GitLab (Module 2).
3.	Show F5XC runtime protection with WAAP (Module 3).
4.	Demonstrate F5XC Web App Scanning as a DAST tool (Module 4).
Table of Contents:
Module 0 – Intro & Environment Orientation
Module 1 – AI-Generated Vulnerable App (Vibe Coding)
Module 2 – CI/CD + Initial Security Controls
Module 3 – Advanced Runtime Security with F5XC
Module 4 – Web App Scanning (WAS)

The lab reinforces a repeatable loop:
Code (AI-assisted) → Commit → Scan (SAST/WAS/API) → Protect (DAST/WAAP/API Sec/Bot/Anomaly) → Improve → Repeat.
